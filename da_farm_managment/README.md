# DA Farm Management

Optional Odoo 19 extension of `field_managment`.

It adds:

- actual material, labor and machinery costing with cost per harvested kg;
- single/mixed planting details and planting density;
- environmental sensor readings prepared for manual entry, import or API sources;
- automatic stock lots and GS1 `(01)` GTIN plus `(10)` lot data;
- historical yield analysis;
- fuel/odometer logs and preventive vehicle maintenance reminders;
- integration with Odoo subcontracting and multi-warehouse flows.

The addon is reusable and contains no customer-specific demo data.
